# DBmarlin data source for Grafana

[DBmarlin](https://www.dbmarlin.com) monitors the performance of your databases and shows where the time goes. This Grafana data source plugin brings that data into Grafana: activity (database time and average active sessions), top SQL and waits, database and host statistics, and DBmarlin alerts, changes and events as annotations.

It needs DBmarlin 6.12 or later and Grafana 11.0 or later.
